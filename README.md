# Carrera de Ciencia de Datos (React + Vite)

    npm install
    npm run dev      # desarrollo
    npm run build    # versión para publicar (carpeta dist/)

Editá los textos, fechas y preguntas en `src/data.js`.
Reemplazá `public/plan-de-estudio.pdf` por tu PDF real (mismo nombre).

## Equipo creador (pie de página)
Editá `equipos` al final de `src/data.js`: hasta 4 integrantes por categoría, con nombre, rol, descripción y foto.
Las fotos van en `public/equipo/` (ej: `foto: '/equipo/ana.jpg'`). Si `foto` queda vacío se muestran las iniciales.

## Mapa
`MAPS_LINK` abre Google Maps. Si además escribís la dirección en `MAP_QUERY`, se muestra el mapa incrustado.
